# Mariscos Langostinos POS

Punto de venta de la marisquería: órdenes por mesa, pantalla de cocina con doble check, corte de caja e impresión de tickets de 80 mm.

- Toda la app está en `index.html` (sin compilación).
- Los datos viven en Firebase Realtime Database (proyecto `app-langos`) y se entra con la cuenta del restaurante (correo y contraseña de Firebase Authentication).
- Vistas: `#ordenes`, `#cocina`, `#corte`, `#menu`.
